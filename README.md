# 小说创作项目

这是一个AI辅助小说创作项目，用于创作多部连载小说。

## 项目结构

```
novel_ai/
├── .claude/
│   └── skills/
│       └── write-novel.md          # 小说创作skill
└── novels/                          # 小说作品目录
    └── 永夜游戏/                    # 第一部小说
        ├── world-building/          # 世界观设定
        ├── characters/              # 人物设定
        ├── outline/                 # 大纲规划
        ├── chapters/                # 已完成章节
        └── progress.json            # 进度追踪
```

## 当前作品

### 《永夜游戏》

- **类型**：无限流 + 系统流 + 悬疑
- **目标读者**：男频，18-35岁
- **预计篇幅**：200-300章（约60-90万字）
- **状态**：筹备中

#### 核心设定

**永夜游戏** - 一个存在于现实世界「夹缝中」的神秘游戏系统，被选中者会被拉入不同副本世界完成挑战。

#### 主要人物

| 角色 | 姓名 | 身份 | 名字寓意 |
|------|------|------|----------|
| 主角 | 顾言 | 图书管理员 | 回顾、眷顾；沉默寡言，用行动表达 |
| 搭档 | 江晚吟 | 独行玩家 | 自由流动；在永夜中吟唱 |
| 导师 | 陆沉 | 传奇玩家/酒吧老板 | 稳重；沉淀了无数故事 |
| 反派 | 沈墨渊 | 永夜教会副会长 | 深沉；堕入黑暗深渊 |
| 挚友 | 苏微雨 | 失踪（核心悬念） | 温柔；如细雨般萦绕 |

#### 核心悬念

1. 苏微雨失踪的真相
2. 永夜游戏的本质
3. 顾言的「前世」记忆
4. 如何打破永夜

#### 剧情结构

- 第一卷：入夜（1-30章）—— 新手觉醒
- 第二卷：破晓（31-70章）—— 成长与团队组建
- 第三卷：迷途（71-120章）—— 探寻真相
- 第四卷：永夜（121-180章）—— 揭秘与抉择
- 第五卷：黎明（181-200/300章）—— 最终对决

## 使用说明

### 启动创作
```
/write-novel 永夜游戏
```

### 查看进度
```
/read novels/永夜游戏/progress.json
```

### 继续写作
```
/write-novel 继续
```

### 创建新小说
```
/write-novel new
```

### 修改设定
直接编辑对应文件：
- 世界观：`novels/[小说名]/world-building/world.md`
- 人物：`novels/[小说名]/characters/*.md`
- 大纲：`novels/[小说名]/outline/*.md`

---

## 创作建议

1. **世界观优先**：花时间完善世界观，避免后期矛盾
2. **人物驱动**：让人物的选择推动剧情，而非剧情推动人物
3. **节奏控制**：紧张副本 → 放松日常 → 下一个副本
4. **悬念维护**：每个副本推进主线悬念，逐步揭开真相
5. **质量保证**：每章至少有一个亮点，结尾留悬念

## 文件管理

每个小说都有独立的目录结构：

```
小说名/
├── world-building/      # 世界观
│   └── world.md
├── characters/          # 人物
│   ├── protagonist.md
│   └── ...
├── outline/             # 大纲
│   └── master-outline.md
├── chapters/            # 章节
│   └── chapter-XXX.md
└── progress.json        # 进度
```

这样的结构方便：
- 同时创作多部小说
- 清晰管理每部小说的设定
- 快速查找和修改内容
