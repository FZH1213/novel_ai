# 副本设定：迷雾庄园

## 基本信息

- **副本名称**：迷雾庄园
- **副本等级**：E级（新手级）
- **副本类型**：解谜类（推理为主）
- **时间限制**：24小时
- **玩家人数**：单人/多人（顾言为单人接入）
- **通关条件**：找出杀害庄园主李伯温的真凶

---

## 庄园背景

### 时间设定
- **年代**：民国时期（1920年代）
- **季节**：深秋，阴雨连绵
- **当天日期**：民国十五年（1926年）农历九月十五
- **案发时间**：昨晚（九月十四）深夜11:00-12:00之间

### 庄园简介
迷雾庄园位于江南某偏僻山间，始建于清朝末年，原为大户人家的私宅。民国初年被商人李伯温买下，经过修缮后作为其家族的隐居之所。

庄园占地约五亩，四周被茂密的树林和终年不散的雾气包围，因此得名"迷雾庄园"。

### 庄园布局

```
  ├─ 停车棚

【主楼】一楼
  ├─ 大厅（案发地点）

  ├─ 主卧（李伯温卧室）

  ├─ 菜地
  └─ 后门（通往山林）
```

## 死者：李伯温

### 基本信息
- **姓名**：李伯温
- **年龄**：52岁
- **身份**：庄园主，前清秀才，后转做药材生意
- **性格**：精明、节俭、有些吝啬，对家人要求严格
- **外貌**：身材微胖，常穿灰色长衫，戴圆框眼镜

### 死亡情况
- **死亡时间**：昨晚深夜11:00-12:00之间
- **死亡地点**：主楼一楼大厅
- **死因**：头部遭受重击，颅骨碎裂，当场死亡
- **凶器**：庄园内的铜制烛台（长约30厘米，重约1.5公斤）
- **现场状况**：
  - 大厅中央有一张红木桌，死者趴在桌边
  - 头部朝向右侧，右后脑有致命伤
  - 现场无明显打斗痕迹
  - 死者手中握着一张纸条，上面写着："今晚大厅，有事相商——李"

### 李伯温的秘密（玩家可调查得知）
1. **生意秘密**：近期药材生意亏损严重，欠下大笔债务
2. **家庭秘密**：打算变卖庄园还债，但未告诉家人
3. **遗嘱**：已写好遗嘱，但内容未知
4. **矛盾**：近期与多人发生争执（具体见嫌疑人动机）

刘三一直在暗中调查，确认了李伯温的罪行。他进入庄园做护院，就是为了等待机会复仇。

近期，他发现李伯温打算变卖庄园、逃离此地。他知道，一旦李伯温离开，他就再也无法报仇了。

所以，他在昨晚动手了。

#### 当晚行踪（自述）
- 晚上8:00在门房值班
- 9:00后回房间休息
- 没有去过大厅，也没有看到任何人

#### 作案过程（真相）
1. 晚上11:00左右，李伯温在大厅等待"有事相商"的人（这个人是谁，李伯温没来得及告诉任何人）
2. 刘三从门房悄悄来到大厅，假装有要事汇报
3. 趁李伯温不备，用大厅里的铜烛台从背后击打其后脑
4. 李伯温当场死亡，没有挣扎
5. 刘三将烛台丢在一旁，伪造现场
6. 悄悄回到门房，假装从未离开

#### 关键证据（玩家需要找到）
1. **门房的时间记录**：刘三当晚的值班记录有涂改痕迹
2. **刘三的鞋子**：鞋底沾有大厅地毯的红色纤维
3. **刘三的房间**：藏有妹妹的遗物（一张照片和一封信，证明复仇动机）
4. **烛台上的指纹**：被擦掉了，说明凶手刻意清理过（其他人没有这个习惯）
5. **李伯温的书房密信**：李伯温近期收到过一封匿名信，威胁他要为两年前的药材事件负责

#### 破绽
- 刘三表面老实，但问及"是否认识药材生意"时，眼神闪烁
- 他的陈述过于完美，反而显得刻意
- 他对李伯温的死表现得过于冷静，甚至有些如释重负

### 后院

- **柴房**：堆放柴火，角落有些被翻动过的痕迹（赵厨师拿过食物）

## 顾言的调查过程

### 第一步：勘察现场（第2-3章）
- 顾言进入庄园，被系统告知规则
- 勘察大厅现场，发现尸体、烛台、纸条
- 使用天赋[静默之眼]查看烛台一小时前的情况——看到一只手握着烛台，但看不清脸

### 第二步：与嫌疑人接触（第4-6章）
- 顾言开始逐一询问七名嫌疑人
- 记录他们的陈述和可疑之处
- **江晚吟登场**：她作为独行玩家，也在这个副本中，但她拒绝与顾言合作

### 第三步：搜查线索（第7-10章）
- 顾言搜查各个房间，找到关键证据
- 发现李伯温的药材生意秘密
- 在书房找到匿名威胁信

### 第四步：推理与分析（第11-15章）
- 顾言分析每个人的动机和行踪
- 排除部分嫌疑（如李明轩的撕碎信纸其实无关）
- 锁定刘三的可疑之处：鞋底纤维、值班记录涂改、对药材的异常反应

### 第五步：验证假设（第16-18章）
- 顾言再次与刘三交谈，试探性地问及药材
- 刘三眼神闪烁，试图掩饰
- 顾言搜查刘三的房间，找到妹妹的遗物和动机

### 第六步：揭露真相（第19-20章）
- 顾言当众指出刘三是凶手
- 展示证据：鞋底纤维、值班涂改、妹妹遗物、复仇动机
- 刘三承认罪行，讲述真相
- 系统判定通关成功

## 江晚吟的登场与合作

### 初次相遇（第4章）
- 顾言在搜查时遇到江晚吟
- 她表现得冷漠，拒绝合作："我不需要搭档。"
- 顾言注意到她手腕上的伤痕（上一轮副本留下的）

### 转折点（第10章）
- 江晚吟独自调查时，差点被误认为是凶手（被王管家发现她在刘三房间）
- 顾言及时出现，用推理为她解围
- 江晚吟的态度开始松动

### 合作（第15章）
- 江晚吟主动找顾言，表示愿意交换情报
- 两人开始合作，分工调查

这个符号，和八年前苏微雨失踪当晚，她日记本上画的那个符号一模一样。

这意味着——苏微雨曾经接触过永夜游戏。

## 写作要点

1. **推理要合理**：线索分布要让读者可以跟随主角推理，不能太简单也不能太难
2. **节奏控制**：搜查→推理→验证→揭露，层层递进
3. **人物塑造**：每个嫌疑人都有血有肉，不是工具人
4. **江晚吟的刻画**：展现她从拒绝到合作的过程，体现她强势但内心柔软的性格
5. **顾言的能力**：展现他的观察力和推理能力，天赋[静默之眼]要合理使用
6. **悬念铺设**：苏微雨的符号线索，为后续剧情埋下伏笔
