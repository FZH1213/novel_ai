# write-novel - 连载小说创作助手

创作一部长篇连载小说，从世界观构建到章节写作的全流程辅助。

## 使用方法

```
/write-novel [小说名称]
```

可选小说：
- `永夜游戏` - 无限流+系统流+悬疑
- 其他小说待创建

如果不指定小说名称，默认为当前正在创作的小说。

## 执行流程

当用户调用此skill时，按以下流程执行：

### 第一阶段：世界观构建

1. **询问用户偏好**
   - 确认题材类型
   - 询问时代背景（古代/现代/未来/架空）
   - 询问基调风格（轻松/严肃/爽文/治愈）
   - 询问男频还是女频

2. **生成世界观设定**
   生成以下内容并保存到 `novels/[小说名]/world-building/world.md`：
   - 时代背景与时间线
   - 核心世界观规则（魔法体系/科技水平/武功系统等）
   - 社会结构与势力分布
   - 主要冲突与矛盾
   - 特殊设定与禁忌
   - 经济体系（如适用）
   - 地理环境

### 第二阶段：人物设计

1. **设计主角**
   生成主角设定保存到 `novels/[小说名]/characters/protagonist.md`：
   - 姓名、年龄、外貌
   - 性格特点与缺陷
   - 背景故事（3-5句话）
   - 核心欲望与恐惧
   - 人物弧光（成长轨迹）
   - 特殊能力/金手指
   - 说话风格与口头禅

2. **设计配角群**
   为每个重要配角生成独立文件：
   - 核心配角2-3人（伴侣/挚友/对手）
   - 反派1-2人
   - 导师/引路人1人
   - 其他关键人物

### 第三阶段：大纲规划

1. **总体结构**
   保存到 `novels/[小说名]/outline/master-outline.md`：
   - 第一卷：开场与设定（约10-20章）
   - 第二卷：冲突升级
   - 第三卷：高潮转折
   - 第四卷：终极对决
   - 结局走向

2. **分卷大纲**
   为每卷生成详细大纲：
   - 主要事件
   - 关键转折点
   - 人物成长节点
   - 伏笔设置

### 第四阶段：章节创作

每次写作章节时：

1. **确认当前进度**
   - 查看已完成章节
   - 确认下一章编号

2. **生成章节内容**
   保存到 `novels/[小说名]/chapters/chapter-XXX.md`：
   - 标题
   - 字数：2000-4000字/章
   - 内容要求：
     - 每章有明确的推进目标
     - 包含对话、动作、心理描写
     - 结尾留悬念或钩子

3. **维护一致性**
   - 人物性格不崩
   - 剧情不矛盾
   - 伏笔不遗忘

### 第五阶段：进度管理

1. **创建进度文件**
   `novels/[小说名]/progress.json` 记录：
   ```json
   {
     "title": "小说标题",
     "genre": "题材类型",
     "current_chapter": 10,
     "total_planned": 200,
     "word_count": 35000,
     "status": "连载中",
     "last_updated": "2024-01-01"
   }
   ```

2. **查看进度**
   每次开始前显示当前进度

## 提示词技巧

生成内容时使用以下技巧：

### 风格控制
```
写作风格：
- [参考作家名]的叙事风格
- 避免使用陈词滥调
- 注重感官细节描写
- 对话自然，体现人物性格
```

### 质量保证
```
要求：
- 每段至少有一个细节描写
- 对话推动剧情或展现性格
- 避免信息堆砌
- 结尾留悬念
```

### 一致性维护
```
注意：
- 保持人物性格一致
- 记住已设置的伏笔
- 时间线清晰
- 称呼/用词统一
```

## 示例用法

```
/write-novel 永夜游戏
/write-novel               # 继续当前小说创作
/write-novel new           # 创建新小说
```
